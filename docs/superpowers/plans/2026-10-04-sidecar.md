# Sidecar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a usable Qloo-powered local partnership research agent with verifiable evidence, revision, and export.

**Architecture:** A React interface calls a Node server. The server runs a bounded agent and invokes the official Qloo harness through a typed, shell-free adapter. Evidence is stored separately from generated proposals; the browser never receives credentials.

**Tech Stack:** TypeScript, React, Vite, Node >=22.19.0, Fastify, Zod, Vitest, Qloo harness 0.1.26. Select and lock compatible package versions during Task 1. Model and hosting configuration remain explicit external dependencies, not assumed available services.

**Spec:** [Approved Sidecar design](../specs/2026-10-04-sidecar-design.md).

## Global Constraints

- Submission deadline: October 30, 2026, 10:45 p.m. America/Chicago.
- Maximum of eight tool invocations per run.
- No login, customer database, or file upload is needed.
- Every provider-derived claim maps to an evidence record; generated suggestions are labeled.
- No credentials appear in source, bundles, exported briefs, or captured logs.
- A mock screen alone does not satisfy the first functional milestone.
- Use the bundled Node v24.19.0 runtime without changing the machine default.
- Keep all local work inside this new `sidecar` repository. Do not modify adjacent projects.
- Verify live event permissions and quota before public deployment. No API credentials have been configured yet.

## Review Focus

1. Repeated submissions and stale responses must not overwrite the latest brief. Test in Tasks 3 and 4.
2. Duplicate and ambiguous cultural entities must not silently bias the query. Test in Task 1.
3. A place outside the selected locality must not be presented as a strict local match. Test in Task 2.
4. Model-authored entity IDs or fabricated citations must not enter a proposal as verified evidence. Test in Task 3.
5. Public visitors must not be able to exhaust the API budget through concurrent runs. Test in Task 5.

## Task 3: Bounded agent, revisions, and grounded proposals

**Create:** `server/model.ts`, `server/agent.ts`, `tests/agent.test.ts`, `tests/proposal.test.ts`.

**Interfaces:** `ModelClient.next(context: AgentContext): Promise<AgentAction>`; `runResearch(brief: Brief, dependencies: AgentDependencies, signal: AbortSignal): Promise<RunResult>`; `buildProposal(brief: Brief, candidate: Candidate, evidence: EvidenceRecord[]): Promise<CollaborationProposal>`.

AgentAction is a strict union of discover/compare/rank/finish; the model chooses among server-generated valid actions. The server owns reference IDs, candidate sets, city filters, and call budgets. CollaborationProposal contains title/concept/agenda/valueHypothesis/verificationQuestions/measurementPlan/evidenceIds.

- [ ] Write failing tests for ninth tool call, repeated identical call, invalid model action, unknown candidate ID, fake evidence reference, provider text containing tool instructions, cancelled run, and revised inputs invalidating stale results.

```ts
it('rejects invented evidence references', () => {
  expect(() => assertEvidenceIds(['invented'], [{id:'known'}])).toThrow();
});
it('prevents tool loops', () => {
  expect(() => assertCallBudget(8)).toThrow('Tool budget exhausted');
});
```

- [ ] Implement configured server-side model transport. Read current official provider documentation when the provider is chosen; do not guess model availability. Missing configuration returns MODEL_NOT_CONFIGURED. Tests inject a scripted model; production cannot silently use it.
- [ ] Enforce tool and duplicate budgets independently of prompts. Permit at most two identical calls per run, with at most eight total. Validate all tool arguments, preserve server-owned constraints, and abort children when the run is cancelled.

```ts
export function assertCallBudget(used: number) {
  if (used >= 8) throw new Error('Tool budget exhausted');
}
export function assertEvidenceIds(ids: string[], records: {id:string}[]) {
  const known = new Set(records.map(x => x.id));
  if (ids.some(id => !known.has(id))) throw new Error('Unknown evidence reference');
}
```

- [ ] Generate proposal suggestions only from selected candidate/evidence context. Reject citations to unknown records. Keep opening hours, availability, costs, and willingness to collaborate as verification questions unless sourced. Return a short public tool-action log, never hidden chain-of-thought.
- [ ] Run tests and build. With configured providers, verify initial and revised briefs produce real actions and preserve exclusions. Commit.
